# 功能待办清单

更新日期：2026-10-28。用于记录当前未实现的功能；讨论中的方案不代表本次已交付。

## 设定管理（本次改动的后续项）

- [ ] 实现新的“一键归类”：确定输入来源、目标栏目/分类、预览结果、确认写入和撤销规则。目前按钮仅显示未实现提示，不发送归类请求。旧 `/api/sections/auto-sort` 后端接口暂保留，前端不调用。
- [ ] 设计已有小说的旧预设栏目合并方案：例如将独立“经济”“历史”栏目的记录归入世界设定的对应分类；保留记录 ID、来源和引用。当前不自动搬运内容，有数据的旧栏目继续显示。
- [ ] 完善删除栏目的恢复入口：当前沿用移除栏目定义、保留内容文件的行为，尚无界面恢复流程；内置栏目及默认世界设定仅允许隐藏。
- [ ] 如需跨栏目批量分类、分类层级或 AI 自动分类，先明确需求，再扩展后端；当前只支持栏目内单层分类及手工分配。

## 创作流程（讨论中，尚未排入本次实现）

- [ ] 对话产出的稿件卡片：命名、预览、来源轮次、多个候选版本。
- [ ] 稿件引用：按钮与拖拽入口、引用内容预览，并确定固定版本和最新版本的规则。
- [ ] 章节管理：章节顺序、章纲与正文关联、生成结果/外部稿件加入章节、追加和替换时的版本恢复。
- [ ] 小说内的灵感与框架：随手记、大纲，以及与设定、章节的关联。
- [ ] 明确稿件处理的定位，并统一稿件编辑、AI 修订和章节之间的流转。
- [ ] 进一步简化设定录入：简述优先、分组编辑、长文本按需展开及更清楚的保存反馈。

## 本轮已完成的边界

统一设定侧栏与管理入口；新作品默认人物、世界、地图、势力四个入口；栏目卡片点击进入、拖动排序、显示开关，以及编辑弹窗中的名称、说明管理；单层分类新增、改名、删除、筛选。复用原有集合和保存接口，没有新增业务 API。空的旧预设栏目在侧栏默认隐藏，可在设定管理中开启；已有记录不自动迁移或删除。
