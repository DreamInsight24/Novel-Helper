# v2610.3 界面改动记录

## 新增

- 小说内设定统一为可折叠分组，右侧齿轮进入设定管理；默认展示人物、世界、地图和势力，其他栏目按需启用。
- 设定条目支持栏目内分类管理与分类/搜索联合筛选；一键归类保留为未实现提示入口。
- 设定管理改为可点击进入的卡片，支持拖动排序；名称和描述通过编辑弹窗修改。

## 调整

- AI 工作站改为对话式布局与底部输入，详细输入支持按栏目和条目选择设定，并携带有上限的历史上下文。
- 设定编辑采用名称、概述与正文，元信息结构集中到设定管理；设定导入集中到管理入口。
- 稿件素材按小说保存，支持文件夹收纳、预览及拖入正文；文本处理工具改为折叠区，新增导入至章节。
- 设定关联支持跨栏目关系图、共享节点、闭环、逐级展开和实时拖线；关系按小说存储，兼容旧势力成员数据。

## 修复

- 修复关联图进入记忆条目后，记忆库页面状态不完整导致列表及编辑区空白的问题。
