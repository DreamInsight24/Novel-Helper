## 当前范围

目前支持简体中文和英文，默认语言与回退语言为简体中文。前后端共用语言资源，界面使用 key 取词。

默认提示词、用户数据及导入导出格式内容按当前实现保留原文。首次启动时选择的语言会决定一部分内置初始化预设（元素模板、自定义栏目、记忆分类、默认模式名与说明、默认记录名、世界地图行列名等）与提供商接口说明的语言，这些内容落盘后不再随界面语言切换而改变；具体判定见 [i18n-inventory.md](i18n-inventory.md) 的第 2 节“豁免清单（不翻译）”、第 4 节“边界处理记录（本次实现）”和第 7 节“JS 汉字残留复核”。

任务 3.2 已实现：首次引导合并为「1/2 选择语言 → 2/2 接口设置」两步、设置页语言下拉与配置持久化（`POST /api/settings/language`，损坏配置备份与日志见 [runtime-flow.md](runtime-flow.md)）。URL 查询参数 `?lang=` 仍可用于临时预览，方法见 [usage.md](usage.md)。
