# NovelHelper

一个本地优先、面向长篇小说创作的开源工具。它把人物、世界观、记忆和写作提示词整理成结构化数据，再按需发送给兼容 OpenAI Chat Completions 的模型接口。

项目默认不包含任何小说数据、个人设定或 API Key。首次启动会在 `app/` 下生成本地数据目录。

## 功能

- **AI 工作站**：左侧配置输入，右侧显示 AI 输出，不再把推理、正文、记忆等多个功能挤在同一块界面。
- **工作提示词**：内置“逻辑写作 / 框架写作 / 完整写作 / 润色修订 / 灵感方案”五种模式，也可以追加本次工作要求。
- **按需带入设定**：人物、记忆、世界观条目、势力、世界地图、当前状态、附加资料都可以逐项勾选；未勾选的内容不会进入提示词。
- **生成锁**：AI 生成期间整个工作站进入全屏锁定状态，输入、按钮和页面切换都被禁用，避免误操作。
- **输出操作**：生成结果可以追加到用户提示词（不覆盖原文）、另存为 TXT/MD、转到纯文本工作站、复制或查看原文。
- **对话历史**：每轮交互自动保存用户提示词与 AI 输出；历史会话可以随时查看、切换为当前对话或删除。
- **节省存储的指针**：历史只保存人物 / 记忆 / 世界观条目的 ID 指针和栏目开关，不重复保存整份设定。读取时按当前数据库解析；指针失效时自动跳过。
- **结构化设定**：人物、势力、道具、装备、自定义栏目都使用可折叠的元素树，支持多层子元素与“是否需要”开关。
- **纯文本工作站**：自动暂存、文件自动保存、空行清理、段内换行合并、查找替换、TXT 导出。
- **本地优先**：服务只绑定 `127.0.0.1`，数据以 JSON 保存在本机；没有遥测，没有云端账号。

## 快速开始

### Windows

1. 安装 Python 3.10 或更高版本。
2. 双击根目录的 `NovelHelper.bat`。
3. 浏览器会自动打开 `http://127.0.0.1:8765/`。
4. 进入「模型设置」，填写 API Key 并保存；也可以设置环境变量 `DEEPSEEK_API_KEY`。
5. 在「AI 工作站」中勾选设定、写用户提示词、选择工作提示词，然后开始生成。

### 命令行启动

```bash
python app/run.py
python app/run.py --port 9000
python app/run.py --no-browser
```

项目只依赖 Python 标准库即可运行；如果环境里安装了 `openai`，会自动使用它，否则退回标准库 `urllib`。

可选安装 SDK：

```bash
pip install -r app/requirements.txt
```

## AI 工作站怎么用

1. 在左侧选择工作提示词：

   - **逻辑写作**：核对时间、地点、人物状态与设定冲突，整理约束、风险与推进节点。
   - **框架写作**：输出场景框架、节拍、关键节点，并整理成可执行的写作提示词。
   - **完整写作**：根据设定与提示词生成完整正文。
   - **润色修订**：按指定问题修改文本，保留事实与情节。
   - **灵感方案**：给出多条有差异的后续方向。

2. 勾选本次需要带入的人物、记忆、世界观条目等，填写当前状态与用户提示词。
3. 点「开始生成」。生成期间工作站会完全锁定。
4. 在右侧查看输出：

   - 「追加到用户提示词」把输出接到当前提示词末尾，不会覆盖已有内容。
   - 「另存为 TXT / MD」保存当前输出。
   - 「转到纯文本工作站」把输出追加到纯文本编辑区。
   - 「查看原文」打开不经过 Markdown 渲染的原始文本。

5. 右侧「当前对话」显示最近几轮；「对话历史」可以查看全部会话、切回历史会话，或点「当前对话」返回。

## 数据与存储

首次启动后生成：

```text
app/
├── data/
│   ├── config.json          模型接口、工具参数、目录设置
│   ├── prompts.json         工具提示词、工作提示词、区块标题
│   ├── schema.json          各类设定的元素模板
│   ├── sections.json        自定义栏目定义
│   ├── state.json           AI 工作站草稿、纯文本草稿、当前会话指针
│   ├── history.json         对话索引（标题、轮数、时间、当前会话）
│   ├── conversations/       每个会话的完整内容（按会话分文件）
│   └── characters.json 等   人物、势力、道具、记忆、地图等数据
└── workspace/
    ├── io/in/               导入目录
    ├── io/out/              导出目录
    ├── out/                 正文与计划
    └── text/                纯文本工作站
```

### 历史记录的存储方式

`data/conversations/<session>.json` 中，每轮只保存：

- `selection`：人物 / 记忆 / 世界观条目的 **ID 指针**、栏目开关、目标字数等；
- `user_prompt`：用户提示词；
- `output`：AI 输出；
- `work_prompt`：本次工作要求；
- `meta`：模型、耗时、token 用量等运行信息。

设定正文不会随每一轮复制。读取历史时会用当前数据库解析指针；条目已删除或为空时直接跳过，不影响其他轮次。

## 导入规则

- **Markdown（.md）只允许导入到「其他设定」**。
- 导入后，在「其他设定」左侧勾选条目，点「搬运选中的条目到…」，即可转成人物、势力、道具、装备、记忆，或任意**自定义栏目**的条目。
- 原 Markdown 内容会保留在条目的「内容 / 补充说明」中，不会被静默丢弃。
- 其他设定仍支持导入 NovelHelper 的 JSON；`.md` 不再出现在人物、记忆、地图等页面的导入入口。

## 项目结构

```text
NovelHelper/
├── NovelHelper.bat          唯一的根目录启动脚本
├── README.md
├── LICENSE
└── app/
    ├── run.py               启动入口
    ├── novelhelper/         后端包（HTTP、数据、AI、提示词、历史）
    │   └── web/             前端页面
    ├── tools/               命令行工具
    └── selftest.py          自检脚本
```

所有运行代码都在 `app/` 内；根目录只保留启动脚本与开源文档。本地数据与产出不会提交到 Git。

## 命令行工具

在 `app/` 目录下运行：

```bash
python tools/writer.py --dry-run
python tools/writer.py -r
python tools/checker.py --all
python tools/fixer.py --text "第3段改成……"
python tools/idea_helper.py -n 5 --save
python tools/md2txt.py --newest
```

提示词、模型和目录都来自 `app/data/config.json` 与 `app/data/prompts.json`，界面与命令行共用同一份配置。

## 自检

```bash
python app/selftest.py
```

自检使用临时数据目录，不联网、不修改真实数据。

## 隐私与安全

- API Key 只保存在本机的 `app/data/config.json`，不会上传到 NovelHelper 自己的服务。
- 服务默认只监听 `127.0.0.1`，不要在没有额外保护的情况下把端口暴露到公网。
- 开源发布前请确认 `app/data/`、`app/workspace/` 没有被提交；`.gitignore` 已默认忽略它们。
- 如果你曾经在旧版本中填写过 API Key，请在发布或分享前撤销并重新生成 Key。
